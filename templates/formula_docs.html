Formula Documentation

This documentation covers the formula syntax supported by REFINED for creating calculated signals from your process data.

Using Formulas

To create a calculated signal:

  1. Enter your formula expression in the Formula Builder panel
  2. Click on active trend tags to insert them into your formula
  3. Provide a name for your new calculated signal
  4. Click Execute to create the signal

Supported Operations

Operator Description Example
+ Addition PI001 + TI001
- Subtraction PI001 - 100
* Multiplication TI001 * 1.8 + 32
/ Division PI001 / PI002
derivative() Rate of change derivative(TI001)
avg() Average of a signal (returns scalar) avg(PI001)
sum() Sum of a signal (returns scalar) sum(TI001)
min() Minimum across scalar/signal arguments min(PI001, TI001, 40)
max() Maximum across scalar/signal arguments max(PI001, TI001)
abs() Absolute value of scalar or signal abs(PI001 - 50)
moving_avg() Rolling mean using sample window moving_avg(TI001, 5)

Tag ID Format

Signal names used in formulas support letters, numbers, and underscores (e.g., PI001, TI001, CALC_001).

Notes

  • When combining two signals, values are aligned on matching timestamps.
  • avg() and sum() return scalars and can be combined with signal math.
  • moving_avg(signal, window) requires a positive integer window.
